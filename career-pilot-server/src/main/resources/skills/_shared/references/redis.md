# Redis 参考要点

本文件是出题参考（考察方向锚点），不是题目本身——题目应结合岗位与候选人背景改写为具体问题。

## 数据结构与场景
- 五种基础类型与典型场景（缓存、计数器、zset 排行榜、set / bitmap 去重）
- 过期策略（惰性删除 + 定期删除）与内存淘汰策略（LRU / LFU 的差异与选择）
- 大 key 与热 key 的识别、危害与治理手段

## 缓存问题
- 穿透（布隆过滤器 / 空值缓存）、击穿（互斥重建 / 逻辑过期）、雪崩（过期打散 / 多级缓存）
- 缓存与数据库的一致性：先删缓存还是先更新库、延迟双删的取舍与落地
- 缓存预热与降级：缓存不可用时业务如何兜底

## 持久化与分布式
- RDB 与 AOF 的差异与混合持久化；主从复制、哨兵与集群分片
- 分布式锁的实现（SET NX EX + Lua 安全释放 + 看门狗续期）与 Redlock 的争议
- Redis 作消息队列的取舍（Stream 的消费组与 ACK 语义 vs List vs Pub/Sub）
