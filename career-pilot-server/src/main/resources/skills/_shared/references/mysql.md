# MySQL 参考要点

本文件是出题参考（考察方向锚点），不是题目本身——题目应结合岗位与候选人背景改写为具体问题。

## 索引
- B+ 树的结构与范围查询优势；聚簇索引与二级索引的回表过程
- 最左前缀原则与索引失效场景（列上函数、隐式类型转换、前导通配符）
- 覆盖索引、索引下推；慢查询的排查路径（explain 的 key / rows / Extra 解读）

## 事务与锁
- 四种隔离级别与 MVCC 的实现（undo log 版本链 + read view）
- 行锁 / 间隙锁 / next-key lock 与幻读的关系
- 死锁的成因与排查方式（information_schema 的锁表、死锁日志）

## 工程实践
- 深分页的优化（游标分页、覆盖索引 + 延迟关联）
- 唯一索引兜底做幂等：并发插入冲突的捕获与重试
- 逻辑删除与唯一索引的冲突及常见解法（复合唯一键含删除标记）
- 时间戳维护：ON UPDATE 不刷新未变化行的坑
