智能求职辅助平台 · Web 原型

毕业设计《基于 Spring AI 的智能体应用开发》的前端原型。 本原型与已完成的后端设计文档一一对应，页面元素直接映射到既有 REST 接口， 可作为 Vue 3 实现的直接依据。

13 个页面，覆盖全部 6 个业务模块 现代简约：白底 + 蓝色主色 + 卡片布局 待实现技术栈：Vue 3 + Element Plus + Pinia

怎么看这套原型

1. 直接点击卡片

每个页面的 HTML 都是独立可打开的，页面间的按钮、链接、返回已经连通， 可以按真实操作路径走一遍完整流程。

2. 页内的演示控件

标注「原型演示」的切换器用来查看同一页面的不同状态 （未分析、加载中、失败、已删除等）。实现阶段这些状态由接口返回值驱动，切换器本身会被删除。

3. 页面顶部的注释

每个 HTML 的源码顶部注明了路由、对应接口与关键业务规则， 交给实现 Agent 时可直接读取，无需另行对照文档。

页面清单

01登录 / 注册
左侧品牌介绍 + 右侧表单，登录与注册同页切换。含密码规则提示与登录失败态。
/loginPOST /api/auth/login
02仪表盘
四项统计、最近匹配记录、能力差距概览、求职准备清单与快捷入口。
/dashboardGET /api/dashboard/summary
03求职智能体
左侧会话列表 + 中间对话区，AI 回复下方展示本次调用的工具与执行状态。含空态引导。
/agentPOST /api/agent/chat
04简历管理
上传弹窗、简历列表（含分析状态）、发起分析、删除确认。含上传成功与失败提示。
/resumesPOST /api/resumes
05简历 AI 分析
概述、技能清单（含证据）、优势与待改进、改进建议。三态：已分析 / 未分析 / 失败。
/resumes/:id/analysisGET .../analysis
06岗位管理
岗位列表、新建与编辑弹窗（描述 10000 字符计数）、删除确认、分析过期标记。
/jobsPOST /api/jobs
07岗位 AI 分析
职责、必备与加分技能、技术栈、学历经验要求。三态：已分析 / 已过期 / 未分析。
/jobs/:id/analysisGET .../analysis
08简历定向优化
优化记录列表与新建优化弹窗（选已有岗位或手动输入 JD）。按目标岗位改写简历：事实不变、逐项可查。
/optimizationsPOST /api/optimizations
09优化工作台
优化前后匹配度对比、维度得分、岗位要求分析、逐项修改说明、待确认问题、可编辑优化稿与导出。
/optimizations/:idGET /api/optimizations/{id}
10AI 面试列表
面试记录列表与创建弹窗（岗位、名称、题型白名单、题数 1–20），含出题等待与失败态。
/interviewsPOST /api/interviews
11模拟面试答题
左侧题目导航 + 答题区 + AI 评价（得分、点评、参考答案、建议）。三态：未作答 / 评价中 / 已评价。
/interviews/:idPOST .../answer
12面试报告
总分、分类得分、逐题明细与提升建议。两态：已完成（有总分）/ 未完成（部分统计）。
/interviews/:id/reportGET .../report
13个人中心
昵称与头像编辑、只读的用户名与邮箱、数据与隐私说明、退出登录。
/profilePUT /api/user/profile

形象为「可爱 AI 机器人 + 简历 + 星星」：圆角方形的头部与简历卡片是同一种形状语言， 机器人本身就像一份站着的小简历。空气感来自两根薄荷绿的星与斜持的卡片，紫色身体与蓝色头部形成主次。

16px 的标签页图标是独立设计的，不是主图标的缩小版 —— 小尺寸下只保留头部与五官， 去掉天线、卡片与星星，让头部占满画布。实测该版本在 16px 下五官仍是精确的品牌深蓝灰像素。

全套资源（SVG / PNG / ICO）见 career-pilot-web/public/images/brand/ · 页面标题统一为「页面名 · 智能求职辅助平台」

  • 阴影：卡片单层轻投影，弹窗提升至 0 12px 32px

  • 字体：系统字体栈，中文优先 PingFang SC / 微软雅黑
  • 间距：以 4px 为基数，卡片内边距 18px，卡片间距 16px
